# Space save: instaladores e atualizações

Este repositório guarda só os **instaladores** do Space save e o arquivo `latest.json` que o programa consulta para saber se há versão nova. O código-fonte não fica aqui.

- Para instalar, baixe o `Space save_<versão>_x64-setup.exe` da [versão mais recente](../../releases/latest).
- Depois de instalado, o programa avisa sozinho quando houver atualização e pergunta se você quer atualizar agora.
- Toda atualização é assinada. O programa confere a assinatura antes de instalar e recusa qualquer arquivo adulterado.

Enquanto o instalador não tiver o certificado de assinatura do Windows, pode aparecer o aviso "O Windows protegeu o computador": clique em **Mais informações** e depois em **Executar assim mesmo**.
